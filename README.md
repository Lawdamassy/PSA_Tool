ParticleArchive (PSA.MK1) - 仕様書 / Readme
概要
ParticleArchive は、Unityシーン上の複数の ParticleSystem を一括で Preset (.preset) 形式として書き出すための作業効率化ツールです。 手動で一つずつプリセットを作成する手間を省き、複数のパーティクル設定をリスト管理して一括保存することが可能です。

主な機能
ドラッグ&ドロップによる一括登録: ヒエラルキー上のGameObjectをまとめてリストに追加できます。

フィルタリング: ParticleSystemコンポーネントを保持していないオブジェクトは自動的に除外されます。

リネーム保存: 書き出し時のファイル名を、ツール上から個別に指定可能です。

一括書き出し: 選択した保存先フォルダへ、一括でプリセット資産を生成します。

使用方法
1. ウィンドウの起動
Unityメニューの [LawTool] > [Particleプリセット一括保存ツール] を選択すると、専用ウィンドウ（PSA.MK1）が開きます。

2. オブジェクトの登録
ヒエラルキーから、プリセット化したいパーティクルオブジェクトを選択します。

ウィンドウ上部の 「DRAG & DROP...」 エリアにドラッグ&ドロップします。

リストに登録されたことを確認します。

3. 名前の設定と整理
Nameフィールド: デフォルトではオブジェクト名が入っています。変更すると、その名前でプリセットファイルが作成されます。

✕ボタン: リストから特定の項目を除外します。

Clear All List: リストをすべてリセットします。

4. プリセットの作成
[プリセットを作成] ボタンをクリックします。

フォルダ選択ダイアログが表示されるので、Assetsフォルダ以下の任意の場所を指定します。

「プリセット化が完了しました。」というダイアログが出れば成功です。

技術仕様・制約事項
動作の仕組み
UnityEditor.Presets.Preset クラスを使用して、対象GameObjectにアタッチされた ParticleSystem コンポーネントの状態をキャプチャします。

ファイル名が重複する場合、AssetDatabase.GenerateUniqueAssetPath により自動的に末尾に数字が付与され、上書きを防止します。

制約事項 (仕様)
対象コンポーネント: 現在のバージョンでは ParticleSystem 本体のみがプリセット化の対象です。

ParticleSystemRenderer や SubEmitter の子階層の設定は、本ツールのプリセット化には含まれません（本体のみの簡易保存運用を想定）。

保存先: 必ずプロジェクト内の Assets フォルダ以下を選択する必要があります。

開発者向けメモ
Undo非対応: 処理の軽量化のため、リスト操作のUndo（元に戻す）は実装されていません。
Renderer や SubEmitter まで含めたPreset化も検討したが、複雑になりすぎたため現状は ParticleSystem 本体のみ対応
サブエミッターなどがついたparticleは基本プレファブとして使うと思うので運用上は問題ないと判断しました。

パス置換: Windows/Mac両環境に対応するため、パス区切り文字は / に統一して処理しています。

ParticleArchiveSummoner (PSA_S.MK1) - 仕様書 / Readme
概要
ParticleArchiveSummoner は、保存されたパーティクルプリセット（.preset）を「書庫」から読み込み、プレビューを確認しながらシーン内へ素早く実体化（召喚）するためのツールです。 マテリアルの差し替えやスケール、親子関係などの設定を召喚時に一括適用できます。
基本的にAssetsに指定しておくと全体をスキャンして出してくれると思います。

主な機能
書庫のブラウズ: 指定フォルダ内のプリセットを自動リストアップ。

リアルタイムプレビュー: リストを選択すると、シーンビューの中央にパーティクルが即座に表示され、動きを確認できます。

召喚カスタマイズ:

召喚時のオブジェクト名指定。

親オブジェクトの自動割り当て。

原点召喚 または シーンビュー位置への召喚選択。

スケール、回転、マテリアルのオーバーライド（上書き）。

Undo対応: 召喚したオブジェクトは Ctrl+Z で削除可能です。

使用方法
1. ウィンドウの起動
Unityメニューの [LawTool] > [Particle召喚ツール] を選択します。

2. 書庫（フォルダ）の選択
[書庫を選択] ボタンを押し、プリセットが保存されているフォルダを指定します。

リストにプリセット名が表示されます。

新しくアセットを追加した場合は [更新] ボタンを押してください。

3. プレビューと設定
リストから任意のプリセット名をクリックします。

シーンビュー上にパーティクルが表示されます。

詳細設定エリアで以下の項目を調整します：

召喚名: 生成されるオブジェクトの名前。

親オブジェクト: 召喚時に自動で子にする親を指定。

スケール/回転: プレビューにもリアルタイムで反映されます。

適用マテリアル: 指定がない場合はデフォルトのパーティクルマテリアルが適用されます。

4. 召喚 (Summon)
[召喚 (Summon)] ボタンをクリックします。

シーン内に正式なGameObjectとして生成され、プレビュー用のオブジェクトは自動消去されます。

技術仕様・制約事項
プレビューの仕組み
HideFlags.HideAndDontSave を使用した一時的なGameObjectを生成しています。

シーン保存時には残らず、ウィンドウを閉じたり別のプリセットを選んだ際に自動で破棄されます。

注意事項
マテリアルの扱い: ParticleSystem 本体にはマテリアル情報が含まれないため、本ツールの「適用マテリアル」スロットを使用して指定します。

座標: 「原点に召喚」にチェックがない場合、プレビュー時（SceneViewのピボット位置）と同じ座標に生成されます。

開発環境
Unity 2018.1 以上（Preset機能依存）

推奨：Unity 3.22f1推奨
